# PretextDemoApp

An Android application demonstrating the use of `@chenglou/pretext` in a breakout-style game on a Canvas.

## Features
- Interactive text-based breakout game.
- Dynamic text layout reacting to moving obstacles.
- Android WebView integration with local assets.

## Setup
1. Open the project in Android Studio.
2. Build and run on an Android device or emulator.

## Tech Stack
- Kotlin / Jetpack Compose (Android)
- JavaScript (Web-based game logic)
- `@chenglou/pretext` for advanced text layout.
